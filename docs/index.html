💡 这个项目是什么

一次旅行 → 一份可视化 HTML 行程方案的制作工作流。沉淀自 2026 冈仁波齐转山实战，包含可复用的组件与本地化资源。

  • 资源全本地化：图片 / 字体 / 地图库全部下载到项目内，不依赖 CDN，离线可用。
  • 高德地图：WGS-84 → GCJ-02 坐标转换，国内地图精准显示。
  • 三级章节导航：一级分组 ≤4 个，小节由 JS 自动生成。
  • 响应式设计：手机友好，手写体标题 + 封面图美化。
